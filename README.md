# Triple Espresso

Nombre del proyecto:
Cafeteria Triple Peaks

Descripción del proyecto:
Landing page que contiene layout general con bloques header, nav, main, content y footer.

Descripción de las tecnologías usadas:
Todos los elementos están ordenados con la metodología BEM y con sus respectivos estilos CSS que contienen también el uso de flexbox y postion para la organización de los mismos. El proyecto aplica tambipen el uso de formularios.

Planes de mejora para el proyecto:
Reducir la cantidad de líneas de código y ejecutar de mejor manera la asignación de clases que se apegue a la metodología BEM
